# Fault-zone anatomy: Session 4 candidate screen

**Status:** prospective ranking, written before implementing the selected candidate. These are geological hypotheses, not score estimates. "Expected improvement" is an expert-prior ranking only; it is not a projected or measured DTI. No candidate uses an external data layer, so none depends on an unverified download. The current lane's input is the pinned `existing_faults.tif`; the optional slip-sense arm can use the already-present INGENIOUS `trace_segments_utm11.csv`.

## Selected validation

H57-K is selected because the required inputs and network-node primitive already exist, while the current model has no explicit topology-distance feature. It will be compared against the latest same-mode, same-budget H57-G control using leave-one-quadrant-out fits on the detached-segment holdout. The new feature is tested alone on every canary fold before the combined model is interpreted. A discriminative AUC above 0.90 is treated as leakage until explained. Every score is produced through `gems57.evaluate_holdout.evaluate` (the shared evaluator) and compared against an independent EDT implementation; no competition slot is used.

The hidden truth remains withheld catalogue geometry, not a verified sample of all genuinely unmapped faults. A positive holdout result is necessary for promotion but is not evidence of a live leaderboard gain. The strict registry overlap gate is independent and can stop a candidate before final placement.

## Validation outcome (after the preregistered screen)

H57-K was tested with the shared pooled evaluator in detached mode, leave-one-quadrant-out (two draws per held-out quadrant), per-cell cap 10,000, floor 0.015. On **22,619 withheld positives**, the H57-G width control measured HOLDOUT-DTI 0.2374226 [0.2014762, 0.2733689]; H57-K measured **0.2423527 [0.2055906, 0.2791148]**. Paired H57-K minus H57-G = **+0.0049301 [0.0014965, 0.0083637]** by spatial quadrant jackknife. All single-feature discriminative-AUC canaries remained ≤0.8982; H57-K's junction-distance feature max was 0.7309. The holdout comparison clears the preregistered research gate.

The pre-placement surface then failed the literal directed 3-px overlap gate. Its rank correlation passed on the two checksum-pinned witnesses (max 0.558503), but 99.872434% of positive surface pixels lay within 3 px of the 13GEMSDOE lattice and 100% lay within 3 px of the 17GEMSDOE E-proba raster. The refreshed public registry index contains 667 unique grid-shaped rasters; all 667 are cached. The first pinned witness fails, so the experiment stops there. No dot allocation, final-dot comparison, TIFF write, validator run, or weekly slot followed. The downloaded/reviewed surface exists only in memory; its decoded-float32 hash is not a TIFF hash.

**Verdict:** holdout-positive, submission-negative. Do not reinterpret continuous positive support as a thresholded dot set or waive the literal rule. The H57-K implementation remains useful as a measured research feature, but it does not meet the user's unique-TIFF/registry gate.
