What Is This Competition?

The DOE GEMS Prize Challenge (DrivenData #306) asks participants to discover geothermal-indicative faults in the GeoDAWN study area (northwestern Nevada, Great Basin) that are not already in the USGS/INGENIOUS fault catalogue. Submissions are single-band GeoTIFF files with per-pixel predicted probabilities, scored by the Distance-weighted Tversky Index (DTI).

The metric (from the problem description):

  • DTI = TP_w / (TP_w + 0.2·FP_w + 0.8·FN_w)
  • Triangular kernel, R = 300 m (3 pixels at 100 m resolution)
  • TP_w: sum over truth pixels of max kernel-weighted prediction within 3 px
  • FP_w: sum over predicted pixels of p(x) × (1 − max kernel weight to truth)
  • FN_w: |truth pixels| − TP_w

⚠️ Common Error: "Predicted values must be in range [0, 1]"

This error occurs when the file contains NaN values or values outside [0, 1]. Our submission file has been validated: all 12,279,160 cells are finite and in [0, 1], with zero NaN values. The competition's own sample_submission.tif has 7,111,787 NaN cells, but our file uses zeros instead of NaN outside the footprint.

What Our Model Does

We use a "fault-zone anatomy" approach: predicting where secondary fault strands (splays, parallel strands, en echelon arrays) sit around known mapped faults, based on shear-zone mechanics.

The model is a gradient-boosted classifier trained on 8 geometric features of each pixel relative to the nearest visible fault: distance, cross-strike offset, along-strike offset, fault length, strike orientation, structural coherence, and local fault density. All parameters are fitted from a hide-and-recover holdout, not taken from textbooks.

Our submission places 25,000 prediction pixels at the locations where the model assigns the highest probability of undiscovered fault strands. The tighter budget (vs the previous 35,000-40,000) is motivated by live-score evidence: across 15 registry rasters, Spearman(dot count, live score) = −0.81, meaning fewer dots at matched quality tends to score higher.

Important: The HOLDOUT-DTI is a local instrument reading, not a projected live score. The holdout withholds catalogue pixels (which are physically near mapped faults), while live scoring tests for genuinely undiscovered faults that may be far from any mapped trace. The transfer from holdout to live is unknown (ρ = 0.14 from sibling calibration).
