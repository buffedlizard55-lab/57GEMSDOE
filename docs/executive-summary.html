Step-by-step submission instructions

Step 1: Download the TIF file

Click the green download button above (or on the home page). Save h57-selective-anatomy-40000-20261009T201645Z-9363b8feb372.tif to your computer.

Step 2: Go to the DrivenData submission page

Navigate to: https://www.drivendata.org/competitions/306/competition-doe-gems/submissions/

Step 3: Click "New submission"

You will see a form with two fields:

  1. File to submit: Click "Choose File" and select the downloaded TIF file.
  2. Note (optional): Paste this submission note:
    top-40000 fault-anatomy prob dots; 9feat LOQO; scale=0.9998

Step 4: Click "Create"

The portal will validate the file. If everything is correct, you will see a success message and the submission will appear on the leaderboard after processing.

Previous rejection: the NaN problem

A previous submission attempt was rejected with "Predicted values must be in range [0, 1]". The root cause was NaN cells outside the study-area footprint (irregularity IR-57-NAN-01). The portal's range check reads NaN as failing both v >= 0 and v <= 1, even though NaN is technically "not a number" rather than out of range.

Fix applied: All 12,279,160 cells are finite float32 values. Outside-footprint cells are set to 0.0. No nodata tag. The current file has zero NaN cells.

The scoring metric

The competition uses a distance-weighted Tversky index (DTI):

  • α = 0.2 (false positive weight)
  • β = 0.8 (false negative weight)
  • Kernel: triangular, 300 m radius (3 pixels at 100 m/px)

False negatives are weighted 4× more heavily than false positives, so the metric rewards covering real fault pixels over being conservative. But every dot costs 0.2 in the denominator, so the allocation must be fitted rather than sprayed.

What this submission does

This is the fault-zone anatomy lane: predicting where secondary strands sit around known faults from shear-zone mechanics. The model uses 9 fitted features derived from distance, orientation, and density of visible mapped faults. Dots are placed at the 40,000 highest-probability cells according to the model.

Key reference: The organisers define a new fault as any fault pixel not already captured by USGS/INGENIOUS, including newly mapped geometry of an existing system (thread 11536). Splays and parallel strands count as new faults.
