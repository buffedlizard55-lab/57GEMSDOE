What this submission is

A binary dot field: PENDING pixels set to 1.0, everything else 0.0, on the official EPSG:32611 100 m grid. Dots sit only inside the active footprint; every dot is off-catalogue. Nothing is written on a mapped fault, because a dot there scores nothing and the false-negative denominator is fixed.

Read the score with care. The holdout numbers on the results page are measured on withheld catalogue pixels, not on the live set. The holdout-to-live rank correlation measured across twelve live submissions in the sibling repository is ρ = +0.14, so a high holdout number is not evidence of a high live score.
