The owner-reported 0.2778: plausible mechanism, unresolved provenance

0.2778 is not ORGANIZER-CONFIRMED. The inspected GEMSDOE32 owner README labels H33-2-B2 UNSCORED; it reports local-mirror 0.267921 and +0.004870 in 4/4 folds, and calls 0.2747 a projection. The `0.2708` base attribution is contradicted in the owner audit: GEMSDOE28 said it had no score; the public-board 0.2708 row belongs to `smashi34` at rank 13. The official leaderboard was not reachable in this sandbox, so neither public row nor owner-reported value was independently verified here.

What the local TIFF comparison does establish: H33-2-B2 has 37,654 positive pixels and is exactly the H27-4 40,199-pixel raster with 2,545 pixels within 2 px of mapped faults removed (no additions). Removing predictions close to the known-catalogue mask could plausibly improve precision / reduce false-positive cost while retaining farther-field coverage. That mechanism fits the local mirror change but does not establish why an organizer score was high; the artifact is documented as unscored and no live score is inferred.

The metric is DTI = T / (0.2(T + n - M) + 0.8K): fewer low-credit predictions can help, while excessive dots cost 0.2 each in the denominator. The mathematical ceiling is 1.0, but this algebra cannot authenticate a score-to-file link. Owner-reported budget correlations are confounded and are labelled OWNER-REPORTED, not causal measurements.
