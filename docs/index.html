What this file is

Fault-zone anatomy: a fitted damage-zone intensity around known USGS/INGENIOUS faults. Withheld-segment d_perp histograms on hide-and-recover folds; bins below 2× the domain base rate are dropped (the brief: keep only the structure the data shows; shrink the budget if the zone is empty). Strike-binned width (H57-I) was tested and is a negative result (0.1999 vs isotropic 0.2617). The shipped arm is the isotropic fitted zone after fixing IR-57-STRIKE-01 (finite strike was previously zeroed, which killed Riedel geometry).
