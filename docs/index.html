What this submission predicts

This lane predicts where secondary fault strands sit around known faults, using shear-zone mechanics. The organizers define a new fault as any fault pixel not already captured by USGS/INGENIOUS, including newly mapped geometry of an existing system (thread 11536).

The model uses 9 fitted fault-zone anatomy features:

FeaturePhysical meaning
dEuclidean distance to nearest visible fault (px)
d_perpCross-strike stepover distance (px)
d_par_absAlong-strike offset magnitude (px)
sideSigned side of the trace (-1 / +1)
log_lenLog length of anchor component — displacement proxy
sin2Cyclic strike encoding, sin(2×strike)
cos2Cyclic strike encoding, cos(2×strike)
coherenceStructure-tensor linearity at the anchor
densityVisible fault pixels within 5 px (500 m) radius

Each feature is fitted to a hide-and-recover holdout — nothing is hard-coded from textbook angles. The model is a gradient-boosted classifier (HistGradientBoosting, max_depth=6, learning_rate=0.08) calibrated to the observed base rate (0.00234) by moment matching. The 40,000 dots are placed at the cells with the highest predicted probability of being a withheld fault pixel.

Physics basis

  • En echelon Riedel shears: Distributed dextral shear experiments (Schreurs, 2003) produce left-stepping en echelon Riedel shears linked by short synthetic shears subparallel to the bulk shear. The classical framework is Tchalenko (1970).
  • Damage-zone decay: Secondary-fracture and strand density decays away from the primary fault (Savage & Brodsky, JGR 2011), with zone width growing with displacement.
  • Walker Lane expression: Left-stepping dextral faults as documented by Faulds, Henry and Hinz in the northern Walker Lane.
